# Changelog

## 0.5.0 — 2026-11-01 (moved into ForgeIndustrial)

- The course moved from the standalone OpcUaExperiments folder into the ForgeIndustrial repository: projects under `src/OpcUaCourse`, documents under `docs/opcua-course`, built as part of `src/ForgeIndustrial.slnx`.
- Retargeted to .NET 11; OPC UA SDK aligned with ForgeSimApp (1.5.376.244, no API changes needed).
- Server endpoint moved to port 4841 so that it can run next to ForgeSimApp (4840).
- Certificates, the NodeSet2 export and the ASP.NET keys no longer go to a `.artifacts` folder inside the repository: they use `UACOURSE_ARTIFACTS_ROOT` or `%LOCALAPPDATA%\UaCourse`.
- Whole course translated to English: documents, lesson file names, UI texts, lab and server messages, comments.
- New dashboard `VFD drive` (own SVG) fed by a second read-only connection to `ForgeSimApp`: `ScreenDefinition.Source`, `ISignalSource`, `SignalSources`, `ForgeSimConnection`.
- New lab `client forgesim [endpoint]` and lesson 19: browse, read and subscribe to the VFD of a `ForgeSimApp` conveyor segment, then design a `VfdType`.

## 0.4.0 — 2026-10-05

- Neutral home page with previews and links generated by ScreenCatalog.
- Dashboards on dedicated routes, direct access, reload and handling of unknown identifiers.
- New UA Lab template with a dark sidebar, light panels and top navigation on mobile.
- Chromium runner updated: twelve page/width combinations, navigation and UA commands.

## 0.3.0 — 2026-10-05

- Implemented RecipeDataType with four fields, binary encoding, StructureDefinition and a partial NodeSet2 export.
- Added BatchRecipe and LoadRecipe with a structured input, validation and value cloning.
- Created the custom-types lab with Read/Call/Publish and rejection of invalid recipes; sequence brought to thirteen labs.
- Added an independent ComplexTypes client without RecipeData and without the server DLL; decoding from metadata verified.
- Integrated recipe loading/reading into the Blazor panel and the Chromium runner.
- Rewrote lesson 09 around the executable code and updated the feature status and the documentation.

## 0.2.0 — 2026-10-05
